# W1 handoff: Wallpapers (71-backdrops v2 + 72-scenes v2). Stopped at the coordinator's time-box call.

## Works (node --check passes; smoke test at 390px: 47 backdrops, 30 of them 3D, 48 gallery cards, no page overflow, no page errors)
- 71-backdrops.js: one shared three.js engine. three@0.149.0 UMD loads from jsdelivr, then unpkg, with a 10 s overall deadline. cdnjs is left out because it never published 0.149.0. One WebGLRenderer is reused across every scene and every preview. Geometries, materials and textures are disposed on each switch. On webglcontextlost it falls back to the 2D twin and goes back to 3D on webglcontextrestored. Pauses when document.hidden, while typing (optional), or when paused. DPR is capped at 1.5 on mobile, 1 on Low.
- Fallback: when a 3D scene fails (offline, CDN, WebGL), a toast appears and the scene's 2D twin (`fb`) runs. The chosen id is kept as `wanted()`, so 3D comes back on the next load.
- Wallpapers view (id `wallpapers`), with entry points from the rail, `/wallpaper [name]`, the `wallpaper_set` tool, Sim intents, a suggest card, a Settings section, and a "🖼 Wallpapers · 3D" button added to the themes picker's packs row (via `view:show`; 70-themes is not edited).
  - Cards show a still drawn once and cached, plus a 3D/2D/NEW badge and an Apply button. Only one tile animates at a time; 3D tiles render through the shared renderer into a 240×150 target.
  - Category filter: All / 3D scenes / Generative 2D / Calm.
  - Controls: Intensity (particles, speed, opacity), 3D quality Auto/Low/High (Auto = low on iOS or ≤4 cores), Pause when typing, Gyro parallax (calls DeviceOrientationEvent.requestPermission on tap), Still image, engine status line with Retry.
- Saving: goes through forge.themes.apply when present, otherwise into the plugin's own ctx.data.
- Theme colours: scenes read --accent / --violet / --bg / --text and restart when the theme changes (MutationObserver + `themes:change`).
- 72-scenes.js: all 21 original-harness scenes are present. Missing ones were ported under new ids where a 2D backdrop already owned the name: wiregrid, matrix3d, waves, aurora3d, fractaltree. Four new scenes: aurora-ribbons, monoliths, nebula-particles, emberforge. New 2D twins: waves-2d, embers-2d, monoliths-2d, fractaltree-2d. Existing backdrop ids are unchanged.
