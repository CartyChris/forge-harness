# S2 handoff — 88-ecc (ECC coding-harness pack)

Files: plugins/88-ecc.js (GENERATED, ~152 KB), tools/gen_ecc.py (template + generator; regenerate with `python3 tools/gen_ecc.py [ECC_DIR]`), tests/t_ecc.py.
Source: github.com/affaan-m/ECC (MIT, © 2026 Affaan Mustafa), local clone in scratchpad/ext/ECC.

## Works (tests/t_ecc.py: 14/14 PASS on `--only 88-ecc,93-agents` and on the full build)
- Bundle (gzip-9 + base64, 77 KB): 14 core agents (12 requested + code-simplifier, performance-optimizer), all 10 rules/common, 5 skills. Plain-JSON index: 71 agents + 314 skills (descriptions capped at 120 chars).
- Decoded with feature-detected DecompressionStream; when that is missing, files are fetched from raw.githubusercontent.com/affaan-m/ECC/main/<path>.
- Roles `ecc-<agent>` are set through forge.agents.setRole (prompt capped at 6 KB; tools mapped Read/Grep/Glob/Write/Edit→files, Bash→run, WebFetch/WebSearch→web). They install once automatically (ctx.data `rolesInstalled`), and the view has an "Install ECC roles" button.
- "ECC loop" toggle pill (uses ctx.prompt with build(), which is skipped for hidden/child threads): loop text + common rules capped at 12 KB.
- `ecc_load {kind,name}` is readonly with gate 'none'. For non-bundled files called by the agent, it calls DS.guard.check('net', url, thread) itself before fetching.
- Commands are registered on `ready` so they can see every other plugin. /plan clashes with 95-picks and becomes /ecc-plan; the other names are used when free. The final mapping is in DS.service('forge.ecc').commands(). /ecc [name|query].
- ECC view + rail icon: search, preview sheet ("Use as prompt"), Export /AGENTS.md (keeps an existing "## Lessons" section), credits/MIT note. Sim intent `ecc plan: …` and suggest card.

## Untested / unverified
- The live raw.githubusercontent fetch (only tested through a mock; CORS is assumed open for raw GitHub). The DecompressionStream fallback path on old iOS has not been run.
- The /plan etc. commands' c.send round trip was not run end to end (the test only checks registration).

## Core notes for the main agent
- Tool `gate` is static, so ecc_load checks the guard by hand for its net leg. A per-call gate (gate(args) → string) in 60-agent would be cleaner.
