## 1b. DeepSeek thinking-mode tool use
- [V] https://api-docs.deepseek.com/guides/thinking_mode/ : thinking supports tool calls (multi-round). With `tools`, `reasoning_content` MUST be passed back in ALL later requests (else HTTP 400); without tools it's ignored. Toggle `thinking:{type:"enabled"|"disabled"}` (extra_body in OpenAI SDK); `reasoning_effort` low|high|max (default thinking ON, effort high; minimal/low->low, medium/high/xhigh->high, max/ultra->max). Responses API: `reasoning.effort` none|low|high|max. Anthropic fmt: output_config.effort. Tools: OpenAI `type:"function"` + name/description/parameters JSON schema; tool results role "tool" + tool_call_id. deepseek-v4-pro: tool_choice "none" disables tools. Thinking ignores temperature/presence/frequency penalty. Strict mode not mentioned on this page.
